# Project Development Guidelines

## Project

This project is being developed as part of my FlyRank AI internship.

## Tech Stack

- HTML
- CSS
- JavaScript
- React
- Node.js
- Git
- GitHub

## Coding Conventions

- Keep the code simple and readable.
- Use clear variable and function names.
- Avoid unnecessary complexity.
- Keep HTML, CSS, and JavaScript organized.
- Test changes before committing them.

## AI Development Guidelines

- Use AI as a development assistant.
- Review AI-generated code before using it.
- Understand the purpose of code before accepting changes.
- Test changes after implementation.
- Ask for explanations when code is unclear.
- Do not add unnecessary features without understanding them.

## Development Goal

The goal is to improve my frontend development skills while learning how to use AI effectively during software development.
